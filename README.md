# NOVIKA | نوویکا
Premium RTL stationery e-commerce portfolio website.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- RTL Persian-first responsive UI
- Premium editorial stationery visual direction
- Product filtering/search
- Wishlist interactions
- Cart drawer with quantities and localStorage
- Toast notifications
- Mobile navigation + bottom navigation
- Newsletter interaction
- Accessibility-friendly labels and semantic sections

Image URLs are remote Unsplash assets; replace them with local optimized assets before production deployment if desired.
